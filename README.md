# 3D Waste Management Map (Streamlit)

This project visualizes a **3D interactive waste‑management map** using **Streamlit + PyDeck** with a clean white/light background.

## Features
- 3D map visualization
- Column / Building layers
- Clean white/light UI
- Fully deployable Streamlit app

## Demo
Run locally using Streamlit.

## Run Locally
```bash
git clone <your-repo-url>
cd waste-3d-map
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python
- Streamlit
- PyDeck
- Pandas
